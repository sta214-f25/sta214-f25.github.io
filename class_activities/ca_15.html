Bootstrap sampling

A bootstrap sample is a sample of rows from the original data, with replacement. Bootstrap sampling can be used to explore the sampling distribution and variability of a statistic. The idea is that variability in resampling from the observed data should reflect variability in resampling from the population.

Grad app data

Suppose we are working with the grad app data, and the model

\[Admit_i \sim Bernoulli(\pi_i)\]

\[\log \left( \dfrac{\pi_i}{1 - \pi_i} \right) = \beta_0 + \beta_1 GRE_i\]

We fit the model in R, and we are interested in estimating \(\beta_1\):

             Estimate Std. Error z value Pr(>|z|)    
(Intercept) -2.901344   0.606038  -4.787 1.69e-06
gre          0.003582   0.000986   3.633  0.00028

Now we would like to explore how \(\widehat{\beta}_1\) varies from sample to sample.

The code below creates a bootstrap sample of the data, and re-fits the logistic regression model on the bootstrap sample:

library(tidyverse)

# bootstrap sample
grad_boot <- grad_app |>
  slice_sample(n = nrow(grad_app), replace=T)

# re-fit model
m_boot <- glm(admit ~ gre, family = binomial, data = grad_boot)

# get estimated slope
coef(m_boot)[2]
  1. Run the code; how does the estimate of \(\beta_1\) from the bootstrap sample compare to the estimate from the original data?
